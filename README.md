# ero-map

Map code and public data for a survey experiment on Excessive Rainfall Outlook map comprehension. All scenarios are hypothetical research stimuli, not real forecasts.

Map data: Natural Earth (public domain). ZIP boundaries: 2010 Census ZCTAs via OpenDataDE/State-zip-code-GeoJSON. ZIP list and coordinates: seanpianka/zipcodes (MIT), drawing on GeoNames (CC BY 4.0), USPS, and unitedstateszipcodes.org.
